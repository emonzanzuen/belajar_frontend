Float dan Multi-column Layout

Ini adalah contoh penggunaan float untuk membuat teks mengalir di samping gambar.

Clearfix digunakan untuk memastikan elemen pembungkus tetap mencakup elemen yang menggunakan float.

Multi-column Layout

Ini adalah contoh teks yang menggunakan multi-column layout. Konten akan dibagi menjadi tiga kolom dengan jarak antar kolom. Setiap kolom juga memiliki garis pemisah.

CSS columns dapat digunakan untuk membuat tampilan teks seperti layout artikel pada koran atau majalah.

Properti column-gap digunakan untuk mengatur jarak antar kolom, sedangkan column-rule digunakan untuk memberikan garis pemisah.
